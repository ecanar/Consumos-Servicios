# Control de Consumo de Servicios

Aplicación para cargar facturas de servicios, extraer datos desde PDFs temporales y analizar consumos.

## Alcance inicial

- Primer proveedor: CNEL
- Primer servicio: electricidad
- PDFs originales fuera de la app
- PDFs procesados temporalmente
- Base de datos inicial: SQLite
